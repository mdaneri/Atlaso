Reset VCFDT staging

This removes the staged VCF Download Tool package, saved Broadcom download token or activation code, application-prodv2.properties configuration, and generated software depot metadata from Atlaso desired state, and disables all download profiles. It does not mutate appliance runtime files until global appliance apply removes the staged and active tool trees.
